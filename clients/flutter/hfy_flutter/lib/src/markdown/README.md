# Markdown

The embedded chat's markdown: a port of `hfyMdParse` (ui.js) and the link
policy. Pure Dart, no rendering.

| File | Role |
| --- | --- |
| `parser.dart` | block and inline parser, `hfyMdParse` |
| `nodes.dart` | immutable output tree |
| `links.dart` | link policy: `hfySafeHref`, `hfySafeUrl`, mailto |
| `url.dart` | WHATWG URL parser behind the policy (http, https, mailto) |

## Limits

- `hfyMdMaxInput` (256 KiB): longer text is not parsed. It comes back as one
  plain paragraph per run of non-blank lines.
- `hfyMdIsolateThreshold` (32 KiB): parse off the main isolate above it.
- `hfyMdDepthLimit` (6): quotes and list items nested deeper flatten to text.

## Widget phase

The widget must do three things the parser does not do itself:

1. Render a capped number of blocks. The block count is not capped: 5 MB of
   short paragraphs gives about 1.7M blocks. Truncate, or build them lazily
   with a list builder.
2. Run `hfyMdParse` through `compute` or `Isolate.run` for text over
   `hfyMdIsolateThreshold` characters.
3. Sanitize lone surrogates before the text is parsed or shown:
   `utf8.decode(utf8.encode(s))` turns each one into U+FFFD and keeps valid
   pairs. `limits_test.dart` pins this.

## Divergences from the browser

The link policy fails closed: a link the browser might make, but the policy
cannot check, stays plain text. Each refused link in
`test/markdown/documented_divergences.json` is generated by
`test/markdown/tool/regen_js_cases.js` from `ui.js`; `url_test.dart` pins the
rest.

- Non-ASCII hosts never link (no UTS #46 mapping).
- `xn--` labels whose decoded text is uppercase, a Kelvin sign, a compatibility
  ligature, led by a combining mark, an enclosed digit, or a dot variant are
  refused, as the browser refuses them.
- Still linked, though the browser refuses them: a label that is not NFC
  (`cafe` plus U+0301), a mixed-digit bidi label, and compatibility letters and
  digits outside those ranges (fullwidth, mathematical alphanumerics, U+017F).
- 154 marks the browser links as the first code point of a label (U+0897
  among them) are refused.
- A bare URL longer than 2048 characters after its scheme stays plain text.
- A mailto link with a raw space is refused.
